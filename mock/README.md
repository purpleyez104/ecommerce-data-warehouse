# Mock Data

此目录保存 V2 数据生成器、可提交的生成参数模板、可重复生成或固定保存的最小业务样例，以及每层的预期结果：

- `generator/`：Python 数据生成器；当前实现位于 `generator/ecommerce_generator_v1/`。
- `config/`：不含秘密值的生成参数模板。
- `samples/`：小规模、去敏、可人工核对的固定验收样本。

开始形成正式样本时，应至少覆盖正常数据、重复事件、跨日、非法状态、退款或撤销、零分母等边界。

不要放入生产导出、个人信息或无来源的大型数据文件。每组样例应说明业务日期、生成方式、输入表、预期输出和对应验证命令。
